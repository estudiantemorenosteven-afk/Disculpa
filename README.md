# Carta para Almendrita

Página estática lista para GitHub Pages. No requiere instalación ni compilación.

## Publicarla en GitHub

1. Crea un repositorio nuevo en GitHub.
2. Extrae el ZIP y sube index.html y la carpeta assets a la raíz del repositorio.
3. Abre Settings > Pages.
4. En Build and deployment, selecciona Deploy from a branch, elige main y la carpeta / (root), y guarda.
5. GitHub mostrará la URL pública de la carta cuando termine la publicación.

La canción se abre por decisión de la persona que visita la página y se reproduce desde el video oficial de YouTube. Se necesita conexión a internet. La página funciona también si no se carga la música.

La foto y la carta quedarán visibles para quienes puedan abrir la URL pública de GitHub Pages.
